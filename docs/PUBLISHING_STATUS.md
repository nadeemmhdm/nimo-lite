# Repository and release destination

The existing project repository is [nadeemmhdm/nimo-lite](https://github.com/nadeemmhdm/nimo-lite). Its private visibility is preserved. The model/application is Nimo Lite.

The initial `nemo-lite` spelling did not resolve to an accessible repository, and creating that repository returned `Resource not accessible by integration (createRepository)`. A later repository search found the existing `nimo-lite` project with push access and a one-line README initial commit. That initial history is retained when integrating the prepared project.

The v0.2.0 release consists of source, a starter model bundle, and SHA-256 checksums. Only original authored public training fixtures are included. Local notes, images, feedback, tokens, environments, and personal trained weights are excluded. Consult the repository's GitHub Releases page for current published availability.
