Privacy & boundaries
Loopback-only server. Cross-origin requests blocked. Mutations require a local session token. No shell, arbitrary URL fetching, or generated code execution is exposed to models.
Dataset text, notes, and model output are untrusted. Injection scanning is a review aid, not a guarantee. Local data is not encrypted: protect your OS account and disk.
Delete samples in Dataset Manager. Export datasets for backup. Full backup: stop the app and copy the data directory to encrypted storage.
Optional online search
No pages automatically enter training or memory. No cross-source verification is implemented.

Live machine resources
One training worker, at most two CPU threads, 32×32 image tensors, and 128-byte text context. Dataset writes are locked while training. GPU is checked inside the worker; CPU-only is tested.
